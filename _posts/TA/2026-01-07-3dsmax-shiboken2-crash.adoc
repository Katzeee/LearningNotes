为了解决DCC中的编辑器十分难用，进行小段代码调试非常麻烦的问题，参考PS的调试方式，希望可以把代码发送到DCC执行。

我尝试在DCC中起一个服务器去监听并执行代码。首先，监听不能跑在主线程，但在3ds Max中，其他线程的print或执行是没有办法被断点的，甚至有可能存在一些rt调用是UB。所以做法就是子线程跑一个监听，然后把代码发送到主线程执行，这里需要用到Qt的一些处理，代码如下（会崩溃版）：

----
import socket
import threading

from PySide2.QtCore import QObject, Signal, Slot, QThread, QMutex, QWaitCondition
from PySide2.QtWidgets import QApplication


class RunnableWaitablePayload:
    def __init__(self, func):
        self.func = func
        self.exception = None
        self.wcnd = QWaitCondition()
        self.mutex = QMutex()

    def wait(self):
        self.mutex.lock()
        RUNNABLE_SIGNAL.sig.emit(self)
        self.wcnd.wait(self.mutex)
        self.mutex.unlock()
        if self.exception:
            raise self.exception

    def run(self):
        self.mutex.lock()
        try:
            self.func()
        except Exception as e:
            self.exception = e
        self.wcnd.wakeAll()
        self.mutex.unlock()


class RunnableSignal(QObject):
    sig = Signal(RunnableWaitablePayload)


class RunnableSlot(QObject):
    def __init__(self):
        super(RunnableSlot, self).__init__()
        self.moveToThread(QApplication.instance().thread())

    @Slot(RunnableWaitablePayload)
    def run(self, payload):
        payload.run()


RUNNABLE_SIGNAL = RunnableSignal()
RUNNABLE_SLOT = RunnableSlot()
RUNNABLE_SIGNAL.sig.connect(RUNNABLE_SLOT.run)


def run_on_main_thread(func):
    if QThread.currentThread() is QApplication.instance().thread():
        func()
        return
    payload = RunnableWaitablePayload(func)
    payload.wait()


HOST = "127.0.0.1"
PORT = 7002


def execute_payload_on_main_thread(payload_str):
    try:
        exec(payload_str, globals(), globals())
    except Exception:
        import traceback

        traceback.print_exc()


def handle_client(conn):
    try:
        data = b""
        while True:
            chunk = conn.recv(4096)
            if not chunk:
                break
            data += chunk

        payload = data.decode("utf-8")

        run_on_main_thread(lambda: execute_payload_on_main_thread(payload))
    except Exception:
        pass
    finally:
        conn.close()


def server_loop():
    server = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    server.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
    server.bind((HOST, PORT))
    server.listen(5)

    print("[RemoteExec] Listening on {}:{}".format(HOST, PORT))

    while True:
        conn, _ = server.accept()
        handle_client(conn)


def start_server():
    t = threading.Thread(target=server_loop)
    t.daemon = True
    t.start()


start_server()

看局部变量快照：

. `part_val = typing.Optional[str]` (这是正确的解析结果)
. `pieces = ['...', 'typing.Optional']` (这是错误的存储结果)
. `result = 'typing.Callable[..., typing.Optional]'`

问题出在这一行代码的执行结果：`pieces.append(to_string(part_val))`

`to_string()` 这个函数在处理 `typing.Optional[str]` 时出错了，看下代码，可以看到专门对 typing module 做了处理，但走错分支了

[source,python]
----
def to_string(thing):
    if isinstance(thing, str):
        return thing
    if hasattr(thing, "__name__"):
        dot = "." in str(thing)
        name = get_name(thing)
        return thing.__module__ + "." + name if dot else name
    # Note: This captures things from the typing module:

那为什么Maya没问题呢？Maya的shiboken2的版本是5.15.2.1，Max的是5.15.1，这个bug修掉了footnote:1[py3.10-prep: Fix parser.py for changed typing module https://github.com/pyside/pyside-setup/commit/4792fd22a38f2f2c0c97ff7b3aadf8c4cf8bc2fd]，看上去shiboken6做了更强的修复footnote:2[PySide6 source code https://github.com/pyside/pyside-setup/blob/a6f69fb04d8dd585974061bd177d11f1eaf3e797/sources/shiboken6/shibokenmodule/files.dir/shibokensupport/signature/parser.py#L380]，不会直接raise了，to_string的实现也做了修改

但问题又回来了，为什么会调用到这玩意，而且为什么时随机崩溃。看了下代码，`pyside_type_init`（异常调用栈的起始点）只在查看函数签名时有被用到，这下破案了，是我在vscode的debug console里面，出现代码补全时，inspect 会访问到 `+__signature__+`，`+__signature__+` 是在cpp层被注册进去的，所以会损失一部分调用栈，最终触发这个异常。

解决也很简单，Python就是方便，在代码执行前直接monkey patch一下：

[source,python]
----
try:
    import shibokensupport.signature.parser as parser_module
    def patched_to_string(thing):
        if isinstance(thing, str):
            return thing
        if hasattr(thing, "__name__") and thing.__module__ != "typing":
            dot = "." in str(thing)
            name = parser_module.get_name(thing)
            return thing.__module__ + "." + name if dot else name
        # Note: This captures things from the typing module:
        return str(thing)
    parser_module.to_string = patched_to_string
except Exception:
    pass
